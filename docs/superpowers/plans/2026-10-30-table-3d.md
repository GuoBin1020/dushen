# 伪3D牌桌与真实素材 实现计划（第一阶段）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把牌局页改成全屏的伪3D牌桌：操作按钮放在桌面上，牌面换成宫廷人像，大小王用 Noto 🤡，筹码和音效用真实素材；德州、炸金花、斗地主三个游戏都改。

**Architecture:**
- 素材用一个 Node 脚本离线生成到 `assets/`：牌面先渲染成 WebP，音效转成 mp3。
- 运行时由新文件 `js/assets.js` 统一给出素材地址：网页版用相对路径；单文件版由 `tools/bundle.py` 注入 data URI 表。
- 座位坐标改由新文件 `js/table-layout.js` 里的纯函数计算，可以在 Node 里测试；绘制代码只负责摆放元素。
- 页面布局用 CSS 实现：牌局进入全屏，桌面用透视倾斜。
- 第二阶段（报牌语音）不在本计划内。

**Tech Stack:**
- 页面：纯 HTML、CSS 和多个共享全局作用域的 `<script>`，没有构建步骤。
- 测试：Node `vm` 单元测试。
- 素材生成和布局检查：无头 Chrome（CDP）。
- 音频转码：本机 ffmpeg。

**Spec:** `docs/superpowers/specs/2026-10-30-table-3d-design.md`

### Task 3: 音效换成采样

**Files:**

**Interfaces:**
- Consumes: Task 1 的 `SFX_FILES`、`assetURL`
- Produces:
  - `sfxLoad() -> Promise<void>`：在第一次 `pointerdown` 时调用。用 `fetch` 加 `decodeAudioData` 把 `SFX_FILES` 里的文件解码成 `SND.buf[key]=[AudioBuffer…]`，单个文件失败就跳过。
  - `sample(key:string, at=0, vol=1) -> boolean`：从 `SND.buf[key]` 里随机取一个播放，成功返回 `true`；没有可用的采样或者 `LOCAL.sfx` 关闭时返回 `false`。
  - `SFX` 的方法名和参数都不变。规则是先 `sample(...)`，返回 `false` 时执行原来的合成代码：
    - `deal(n)`：先 `shuffle`，然后每隔 0.09 秒播一次 `slide`，共 n 次。
    - `flip()`：`place`。
    - `fold()`：`shove`。
    - `chips(n)`：n≤3 时 `chipLay`，否则 `chipStack`。
    - `allin()`：保留合成的音效，并在 0.6 秒时加一个 `collide`。
    - `pot()`、`win()`：`handle`。`win` 原来的上行音阶保留。
    - `check`、`ding`、`clash`、`fanfare`：不变。
