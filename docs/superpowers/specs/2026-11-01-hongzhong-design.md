# 红中麻将 设计

日期：2026-11-01
状态：用户已确认

标记说明：
- 没有标记的内容是用户确认过的。
- 「【我定的】」是 Claude 定的，读的时候请重点检查。
- 「【留给实现者】」是写代码时可以自己决定的细节。

## 1. 为什么做

在现有的德州扑克、炸金花、斗地主之外，再加一个用户和朋友平时玩的红中麻将，玩法参考湖南红中麻将。和其他游戏一样，只供朋友娱乐、学习，积分没有任何价值，开局照常提示「禁止用于赌博」。

## 2. 目标

1. 首页「游戏」里新增「红中麻将」，支持单机（3 个电脑玩家）和联机（真人不够时由电脑补位），和斗地主的方式一样。
2. 牌桌沿用现有的伪3D牌桌、角落按钮、聊天气泡、出牌限时、托管、暂时离桌、教练、统计和结算。
3. 规则见第 3 节，可以改的规则做成开局选项。

## 3. 规则

### 3.1 牌和人数
- 共 112 张：万、条、筒各 1 到 9，每种 4 张，共 108 张，另加 4 张红中。没有风牌，也没有发财、白板。
- 4 人。每人 13 张，庄家 14 张，庄家先打。
- 出牌顺序是逆时针：我打完轮到右边（下家），然后是对面，再是左边（上家）【我定的：和斗地主一致】。

### 3.2 红中
- 红中是赖子，可以当任意一张万、条、筒。
- 红中不能打出【我定的：湖南红中的常见做法】。
- 红中不能拿来吃、碰、杠别人打出的牌，只能在自己手里组牌【我定的】。
- 起手摸到 4 张红中，可以直接胡（见 3.4）。

### 3.3 吃、碰、杠
- **吃**：不能吃（2026-11-01 用户要求去掉）。
- **碰**：任何人打出的牌都能碰。
- **杠**：
  - **明杠**：别人打出的牌，你手里有 3 张同样的，可以杠。
  - **暗杠**：自己手里有 4 张同样的。
  - **补杠**：碰了之后又摸到第 4 张。
  - 杠完从牌堆尾部补摸一张【我定的】。
- **抢杠胡**：别人补杠时，如果那张牌正好能让你胡，可以抢过来胡。开局选项，默认勾选【我定的】。
- **同一张牌多人要时的优先级**：胡 > 杠、碰 > 吃【我定的：通用规则】。
  - 多人都能胡同一张牌时，只算按出牌顺序离打牌人最近的那一家【我定的：截胡，不做一炮多响】。
  - 碰和吃同时有人要时，碰优先。

### 3.4 怎么算胡
- **平胡**：4 组顺子或刻子，加 1 对将。任何对子都能做将，不要求 2、5、8。
- **七对**：7 个对子（不能有碰、吃、杠）。
- **四红中**：起手 4 张红中直接胡。
- 红中可以当任意牌参与组成以上牌型。

### 3.5 自摸和点炮
- **默认只能自摸**：开局选项「允许点炮」默认不勾选。
- **勾选「允许点炮」后**：
  - 别人打出的牌能让你胡，就可以胡。
  - 另一个开局选项「手里有红中只能自摸」默认勾选【我定的】：勾选时，手里有红中的人不能点炮胡。

### 3.6 算分
所有分数都乘以开局选的「底分」，换算成积分（筹码）【我定的：和斗地主的底分一样】。

| 情况 | 谁付分 |
|---|---|
| 自摸 | 其他 3 家每家付 2 分 |
| 点炮 | 打出那张牌的人一个人付 2×3 = 6 分（替其他三家付） |
| 抢杠胡 | 被抢杠的人一个人付 6 分【我定的：按点炮算】 |
| 七对 | 胡牌分翻倍 |
| 四红中 | 按自摸算【我定的】 |
| 无红中胡 | 开局选项「无红中加倍」，默认不勾选【我定的】：勾选时，手里没有红中就胡了，胡牌分翻倍 |
| 明杠 | 打出那张牌的人付 3 分 |
| 暗杠 | 其他 3 家每家付 2 分 |
| 补杠 | 其他 3 家每家付 1 分 |
| 抓鸟 | 胡牌后从牌堆翻 N 张（开局选 0 / 2 / 4 / 6，默认 2【我定的】）。翻到 1、5、9 或红中算「中鸟」，每中一只，每个付分的人多付 1 分 |
| 流局 | 牌摸完没人胡，胡牌不算分，杠分照算 |

- 翻倍可以叠加，比如七对加无红中就是 ×4【我定的】。
- 杠分在杠的当时就结算，牌局结束不退回【我定的】。

### 3.7 庄家和局数
- 谁胡谁下一局坐庄；流局时庄家连庄【我定的】。
- 一局结束就是一手结束，由房主点「下一局」或自动发下一局，和其他游戏一样。整场在「结束并结算」时汇总。

## 4. 牌桌界面
- **座位**：我在下方，下家在右边，对家在远端正中，上家在左边。头像、昵称、积分沿用现有座位样式。
- **我的手牌**：在最下方，按万、条、筒、红中排序，红中有明显的「赖」标记【我定的】。摸到的牌放在最右边，和其他牌隔开一点。点一下选中、再点一下或点「出牌」打出【我定的】。
- **别人的手牌**：显示牌背，以及剩几张。
- **碰杠的牌**：每副缩成一张，牌上贴「碰」「杠」或「暗杠」（2026-11-01 用户要求）。左边的人放在座位右边，右边的人放在座位左边，上方的人放在座位下面，我的放在手牌左上方。
- **打出的牌**：所有人打出的牌按出牌顺序一起排在桌面中间，每行放几张按屏幕宽度自动算，被碰杠拿走的牌从里面去掉。最新打出的那张高亮（2026-11-01 用户要求）。
- **剩余张数**：横屏在右上角；竖屏放在记牌器下面一行，关掉记牌器或教练时单独显示在同一位置（2026-11-01 用户要求）。
- **记牌器开关**：设置页单独有「显示记牌器」（斗地主、红中麻将），默认打开，和教练开关互不影响（2026-11-01 用户要求）。
- **桌子中间**：打牌时是牌河；一局结束时弹出结果框，显示胡牌人的牌和抓鸟。庄家标在座位上。
- **操作按钮**：
  - 轮到我时显示「出牌」。
  - 别人打出的牌我能吃、碰、杠、胡时，弹出这几项和「过」。
  - 可以吃的组合不止一种时，弹出选择面板【我定的】。
- **牌面图片**：FluffyStuff 的 riichi-mahjong-tiles，CC0 公有领域，用户已确认样式。
  - 牌面底板（Front）和符号叠加显示。
  - 只用万、条、筒 1 到 9、红中、牌背。
  - 牌背目前是纯红色，加一层和扑克牌背类似的花纹【我定的】。
- **音效**：没有能放心用的麻将录音（T-STUDIO 的麻将音效禁止二次分发，不用）。改用项目里已有的 Kenney CC0 音效，调整音高和长短：
  - 摸牌、打牌用骰子和筹码碰撞类的短声。
  - 吃、碰、杠、胡各一个提示。
  - 具体对应关系【留给实现者】。
- **报牌语音**：吃、碰、杠、胡，以及自摸、点炮，沿用现有的 `say()` 浏览器朗读。第二阶段的预合成语音以后再一起做。
- **大角标**：麻将牌图案本身足够清楚，不加大角标【我定的】。
- **横竖屏**：都要支持。竖屏时 14 张手牌一行，手机上每张宽约 28px，比较小。第一次竖屏打开时提示「横屏体验更好」，和斗地主一样【我定的】。

## 5. 电脑玩家和教练
- **电脑玩家**：
  - 按「离听牌还差几步」（向听数）选择打哪张，红中一定留着。
  - 能胡就胡。
  - 碰、杠、吃要判断能不能让离听牌更近，不能就过。
  - 实现方式【留给实现者】。
- **教练**：
  - 轮到我时推荐打哪张，并说明原因，比如「打这张还差 1 步听牌」。
  - 听牌时显示能胡哪几张、还剩几张。
  - 别人打牌我能吃碰杠时，建议要还是过。
  - 和斗地主教练一样，只用公开信息：我的手牌、所有打出和亮出的牌。
- **记牌器**：显示每种牌还有几张没出现过（不在我手里、没打出、没亮出），位置和斗地主的记牌器一样放在顶部栏下面【我定的】。

## 6. 联机、限时和托管
- 联机方式和斗地主一样：由房主计算牌局，客人只收到自己能看到的部分。别人的手牌只发张数，牌堆不发给客人。
- 出牌限时和托管沿用现有设置。超时时：
  - 总是按教练推荐打牌，能胡时胡；不管「超时后采用教练方案」和教练开关有没有勾选（2026-11-01 用户要求，斗地主也一样；这个选项只对德州、炸金花有效）。
  - 别人打牌后的碰杠询问，超时算「过」，但能胡时自动胡【我定的】。
  - 托管和暂时离桌的规则和斗地主一样。麻将必须 4 个人，离桌的人由电脑托管，不离座。
- 加密的联机核心原则上不改。如果新增一种游戏必须改联机核心（比如消息类型白名单），按私有仓库的流程改明文、重新加密，只提交 `js/net-online.enc.js`【我定的】。

## 7. 不做的事
- 不做风牌、箭牌（除了红中）、花牌。
- 不做杠上开花、海底捞月、清一色、碰碰胡等额外番型（以后可以加）。
- 不做三人麻将。
- 不用任何商业麻将游戏的图片、音效。

## 8. 测试和验收
- **规则测试（Node）**：
  - 胡牌判断：平胡、七对、四红中、红中当任意牌、不能胡的情况。
  - 吃碰杠合法性：只能吃上家、红中不能吃碰杠也不能打出。
  - 优先级和截胡。
  - 抢杠胡。
  - 各种算分，包括点炮 6 分、杠分、抓鸟、翻倍叠加、流局。
  - 庄家轮换。
- **流程测试**：4 个电脑玩家自动打 200 局，不报错、不卡死，每局积分总和为 0。
- **布局检查**：沿用 `tools/layout-check.mjs`，所有尺寸下不滚动、不遮挡，手牌一行放得下。
- **联机**：两个标签页一个建房一个加入，打完一局。
- **单文件版**：打包后离线能打开，牌面能显示。
- **素材**：`assets/CREDITS.txt` 和 README 写明麻将牌来源和许可证。

## 10. 补充细节（审阅后补充；第 2、5 条用户已确认，其余【我定的】）
1. **牌堆和流局**：不留底牌，牌堆摸完就流局。抓鸟的牌在胡牌后从牌堆顶依次翻；牌堆不够 N 张就有几张翻几张。牌堆没牌时不能杠（杠了补不到牌）。
2. **点炮、抢杠时的鸟分和翻倍**（用户已确认）：
   - 胡牌分 = 基础 2 分 × 翻倍（七对、无红中），鸟分在翻倍之后再加，不翻倍。
   - 自摸：其他 3 家每家付「胡牌分 + 中鸟数」。
   - 点炮、抢杠胡：由一个人付「(胡牌分 + 中鸟数) × 3」，也就是替其他三家一起付。
   - 抢杠胡时，被抢的那次补杠不算杠分。暗杠不能被抢。
3. **红中和杠**：红中不能参与任何杠（不能凑成暗杠、明杠、补杠），4 张红中也不能杠。
4. **七对**：手里 4 张一样的算两对。红中可以补成对子。起手四红中和七对同时成立时，按分高的算。
5. **点炮开启后**（用户已确认）：
   - 所有胡法都能点炮，「无红中加倍」也生效。
   - 勾选了「手里有红中只能自摸」时，手里有红中就一律不能点炮胡，也不能抢杠胡。
   - 「允许点炮」不勾选时，别人打出的牌一律不能胡，但「抢杠胡」是单独的开关，勾选时仍然可以抢杠胡。
6. **起手四红中**：发完牌后，轮到这位玩家第一次行动时（庄家就是一开始）可以宣布胡，按自摸算分。
7. **无红中**：胡牌时手里（包括胡的那张）只要有任何一张红中，就不算无红中，不管它当成了什么牌。
8. **询问和等待**：别人打出一张牌后，所有能吃、碰、杠、胡的人同时收到询问，都选了或者超时后，按「胡 > 杠/碰 > 吃」结算。同一张牌不可能同时有两个人碰或杠（一共只有 4 张）。
9. **只剩红中**：正常情况下手里只剩红中一定能胡（红中可以组成任何对子）。万一出现只能打出红中的情况，允许打出红中，不会卡住。
10. **整场结束**：和斗地主一样，由房主点「结束并结算」，没有固定局数。
