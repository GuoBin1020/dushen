## 1. 为什么做

现在的牌局页面是普通网页的样子：牌桌是平面椭圆，扑克牌是 CSS 画的方块，操作按钮在牌桌下面的面板里，音效是代码合成的「嘀嘀」声。用户觉得「有点普通，不好看」，希望做成像《欢乐斗地主》那样的游戏画面。

## 2. 目标

1. **伪3D视角**：视角在玩家自己这一头。牌桌近边超出屏幕底部，远边在屏幕上方，越远越窄。参考效果图：`.superpowers/brainstorm/71307-1793364260/content/table-3d-v4.html`（横屏）和 `table-3d-portrait.html`（竖屏）。
2. **出的牌落在桌面上**：别人出的牌放在他面前的桌面上；斗地主的 3 张底牌在桌子远端正中；德州的公共牌和底池在桌子中央。这些牌跟着桌面一起倾斜。
3. **按钮放在桌面上**：出牌、加注这些操作按钮排成一排圆角大按钮，放在自己手牌正上方的桌面上，不再放在牌桌下面的面板里。
4. **游戏画面占满屏幕**：进入牌局后，去掉页面的标题栏、边距和底部说明，牌桌铺满整个浏览器窗口。主页和联机大厅保持现在的样子。现有的「横屏全屏」按钮（隐藏浏览器地址栏）保留，放在角落；不会一进牌局就自动进入浏览器全屏。
5. **横屏和竖屏都做**：
   - 竖屏风格和横屏一样，只是桌子更高更窄；对手沿桌子两侧往远处排，手牌叠得更紧。
   - 竖屏时桌面上出的牌只稍微倾斜，比横屏平，方便看清。
6. **真实素材**：
   - 扑克牌面：用传统宫廷人像（Byron Knoll 的 Vector Playing Cards，公有领域，用户在三套牌面里选了这套）。
   - 音效：用 Kenney Casino Audio（CC0）替换合成音效。
   - 筹码：用 Kenney Boardgame Pack（CC0）里的筹码图。
7. **报牌语音**：男声、女声各一套，预先合成好放进资源里，游戏里直接播放，不需要联网。内容包括斗地主报牌、德州和炸金花的动作，以及聊天快捷语。**这一项等用户换到快的网络再做**（现在网速只有十几 KB/s，装语音模型要 8～10 小时）。

范围是三个游戏全部：德州扑克、炸金花、斗地主【我定的：用户没有单独说，但三个游戏共用一个牌桌页面】。

## 3. 不做的事

- 不做真正的 3D（WebGL、3D 模型），只用 CSS 透视和图片做出立体感。
- 不改游戏规则、电脑出牌、教练算法、联机协议和卡密逻辑。
- 加密的联机核心（`js/net-online.enc.js`）原则上不改。如果实现时发现它直接操作了被改版的界面元素（比如 `#actions`、`.rail`），由 Claude 按私有仓库的流程修改明文、重新加密，只提交加密文件【我定的】。
- 不用《欢乐斗地主》或其他商业游戏的任何图片、声音、语音。
- 不用 macOS 自带的「朗读」生成语音：苹果的许可只允许个人、非商业使用，不能公开发布。

**什么情况算做失败了（即使功能都能用）：**
- 按钮或手牌挡住别人的座位、出的牌、公共牌；
- 页面出现滚动条，或者竖屏时因为按钮多少变化而跳动（之前修过的问题不能回来）；
- 桌面倾斜后牌面上的字太小、看不清；
- 手机上首次打开明显变慢。

处理方式：
- **牌面**：
  - SVG 原文件共 8MB，太大。转成小图片放进 `assets/cards/`：用无头 Chrome 渲染，再压缩成 WebP 或 PNG【我定的】，目标总大小在 1MB 左右。
  - 图片宽度要能在高清手机屏上看清，具体尺寸【留给实现者】。
  - 黑桃 A 不用原图（有资料说是另一位作者画的，版权不明），自己画一张。
  - 斗地主的大王和小王不用原来的 Joker 图。牌面四角写「大王」「小王」（竖排），中间是 Google Noto Emoji 的 🤡 图（`emoji_u1f921.svg`，Apache-2.0，用户在 Noto 和 Twemoji 中选了 Noto）。
    - 大王：彩色，角上的字是红色。
    - 小王：同一张图的灰度版，角上的字是黑色。
    - 效果见 `.superpowers/brainstorm/98536-1793367064/content/joker-v2.html` 的 A。
- **牌背**：用 Kenney 桌游包里的一款红色牌背【我定的】。
- **音效**：
  - OGG 转成 mp3（iPhone Safari 对 OGG 支持不稳定），放进 `assets/sfx/`。
  - 现有的 `SFX.*` 调用点不变，只换声音来源。对应关系【我定的，用户试听后没有反对】：

    | 场景 | 音效 |
    |---|---|
    | 开局 | 洗牌 |
    | 发牌 | 滑牌 |
    | 出牌 | 放牌 |
    | 弃牌 | 推牌 |
    | 跟注 | 放筹码 |
    | 加注 | 叠筹码 |
    | 全下 | 筹码碰撞 |
    | 赢下底池 | 收筹码 |

  - 没有合适素材的提示音（比如轮到你、转盘停下）保留现在的合成声音。
- **桌布、木边、背景**：用 CSS 和 SVG 画，包括渐变、细噪点纹理和光影，不另外下载贴图【我定的：网速慢，而且画出来的体积小；效果不够好再补 CC0 贴图】。
- **出处说明**：README 里写明每个素材的作者、来源和许可证；`assets/` 下放一份 `CREDITS.txt`。
- **单文件版和离线缓存**：
  - `tools/bundle.py` 打包时把素材一起打进去（转成 data URI）。
  - `sw.js` 的缓存列表加上素材文件，并升级缓存版本号。

## 5. 牌桌和座位

- 牌桌形状和效果图一致：
  - 梯形透视，远边圆角；
  - 木质外框，外框内侧有一条亮边；
  - 绿色绒布，中间亮、四周暗；
  - 背景是暗色房间。
- 座位排在桌子远处和两侧，远处的座位稍小一点，看起来有远近【我定的】。德州最多 9 人（代码里 `MAX_SEATS=9`），竖屏时对手排成两三层。
- 自己的座位（头像、昵称、筹码）放在左下角或手牌旁边，和效果图一样。
- 自己的手牌在最下面放大显示，不跟着桌面倾斜，方便点选。斗地主 20 张牌要能在一行里放下。
- 下注筹码、出的牌、公共牌、底池、桌面提示文字（`V.msg`）都放在桌面上，并带透视倾斜（竖屏时倾斜更小）。
- 现有的动画层（`#fx`，比如发牌、筹码飞动）继续能用，起点和终点要跟着新的座位位置走。
- 点别人的下注筹码会放大显示，这个功能保留。
- 对手的底牌（摊牌亮牌、学习模式「显示对手底牌」、炸金花每人 3 张）还是放在各自座位的头像旁边，用小牌、不倾斜，摊牌时稍微放大【我定的】。
- 牌桌以外用到牌的地方（规则面板的牌型示例、教练和记录面板）也换成同一套新牌面，全站只有一套牌面绘制【我定的】。

## 6. 操作按钮

现在 `#actions` 面板里的东西搬到桌面上，规则是：
- 主操作（弃牌、过牌、跟注、加注、全下，看牌、比牌，叫地主、抢地主、加倍，出牌、不要、提示、重选）是手牌上方的一排圆角大按钮，颜色区分：
  - 灰色：弃牌、不要、不叫；
  - 黄色：提示；
  - 绿色：跟注、出牌；
  - 红色：加注。
- **德州加注**【我定的】：点「加注」后，按钮上方弹出一个小面板，里面有滑块、「最小 / ½ 池 / ⅔ 池 / 1 池」快捷金额和「确定」按钮，加注金额在这里确认。效果图里放在右侧的竖滑块不采用。
- **炸金花**：「比牌」和每个对手的比牌按钮、「加注」的几个金额，也用同样的弹出小面板【我定的】。
- **等待和提示类文字**（比如「等待某某行动…」、掉线提示、本手输赢）显示在按钮这一排的位置，没有按钮时就只显示这行字【我定的】。
- **教练建议**：被推荐的按钮继续高亮（现有的 `is-rec`），建议文字显示在按钮上方的小标签里。
- **「结束并结算」「下一手」「补码」「让电脑顶上」**：「下一手」「补码」放在按钮这一排；「结束并结算」收进角落的菜单【我定的】。
- 按钮在手机上要够大，好按。按钮出现或消失时不能让手牌和桌面跳动。

## 7. 角落按钮和面板

- 屏幕左上角是小按钮：设置/菜单、教练、统计、规则、横屏全屏。右上角是牌局信息：盲注或底分、倍数、记牌器开关。竖屏时缩成图标。
- **电脑上**【我定的】：现在右侧的教练、统计、记录栏（`.rail`）不再常驻，和手机一样收进角落按钮打开的面板（现有的 `#sheet`）。这样电脑上牌桌也能铺满窗口。
- 聊天还是悬浮气泡，位置不变。
- 主页、联机大厅、结算页不改版。

## 8. 报牌语音（第二阶段，等快网络）

- 用 Kokoro-82M-v1.1-zh 在作者本机合成。模型代码和权重都是 Apache-2.0，已核对 Hugging Face 官方页面。合成需要 Python 3.10～3.12（本机只有 3.13）、PyTorch 和约 330MB 的模型。
- 先选三四个男声、女声，各念几句给用户试听，用户选定一男一女后再批量合成。
- **句子清单**【我定的，合成前给用户确认；以代码里 `say()` 实际念的句子为准，下面是大致范围，赖子模式的软炸、硬炸、纯赖子炸也要包括】：
  - 斗地主：叫地主、不叫、抢地主、不抢、加倍、不加倍、要不起、不要、单张（3 到大王）、对子（对 3 到对 2）、三张、三带一、三带二、顺子、连对、飞机、四带二、炸弹、王炸、我只剩一张牌了、我只剩两张牌了、春天。
  - 德州和炸金花：过牌、跟注、加注、全下、弃牌、看牌、比牌。
  - 聊天快捷语：现有 `QUICK` 里的 10 句。
- 每句一个 mp3，放在 `assets/voice/male/` 和 `assets/voice/female/` 下，两套总共约 1～2MB。
- **播放**：
  - 每个座位按性别固定一种声音；电脑玩家随机分配【我定的】。
  - 现有 `say()` 用浏览器语音朗读，改成优先播放预合成的 mp3，找不到对应句子时才退回浏览器朗读。第一阶段不改 `say()`。
  - 语音开关沿用现有的 `LOCAL.voice`。
- 合成用的脚本放在 `tools/`，不放模型文件。

## 9. 验收

- 在无头 Chrome 里检查以下尺寸：手机竖屏 393×873、360×780，手机横屏 873×393，平板，电脑 1280×800。三个游戏、2 到 9 人。要求：
  - 没有滚动条；
  - 按钮不挡住任何座位、出的牌和公共牌；
  - 一手牌里按钮变化时手牌不跳动。
- 现有 Node 测试全部通过：斗地主规则和流程，卡密。
- 联机对局可以正常进行。私有仓库里的联机测试要在本机克隆后跑。
- 单文件版打包后能离线打开，图片和声音都能显示、播放。
- iPhone Safari 能播放音效。
